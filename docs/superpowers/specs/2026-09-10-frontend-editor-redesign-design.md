# 前端行为树编辑器重新设计（节点画布 + 槽位引用 + 一文档一树）

> 日期：2026-09-10
> 状态：探索稿（设计讨论中，已确认核心决策，余下细节待续）
> 范围：M9a 前端编辑器（行为树可视化编辑）、联动：M2 DSL（一文档一树）、M7 执行（ref 挂载根）
> 关联：契约 §4.1（文档与块）、§12.5（前端复合节点视图）；方案 2（主块+附属块）将被本设计取代

## 背景与动机

现有前端编辑器（拖拽嵌套列表 + 单块编辑）与用户期望相差甚远：

1. **呈现形式**：当前是"嵌套卡片缩进列表"（`CanvasTree` 的 `tree-node` 套 `tree-node__children`），不是真正的节点树/画布。
2. **引用块参数不可编辑**：`NODE_FIELD_DEFS.ref` 仅 `ref` 一个字段（model.ts:39）；`nodeFromYaml` 只取 ref 目标串、**静默丢弃 args/returns**（model.ts:313）；`nodeToYamlValue` 也只输出目标串——**编辑器打开含参数的 ref 再保存，参数即丢失**（数据破坏性缺陷）。
3. **块声明不可见/不可编辑**：`BlockDoc.decl`（inputs/outputs）只"保留原文"，无 UI 展示与编辑。
4. **附属块概念冗余**：树形呈现下"子树 = 节点下加节点"，无需独立附属块文档。

用户期望：真实画布节点、节点位置程序自适应（非拖拽）、ref 可展开/收缩、引用块可下拉选文档并自动加载其 inputs/outputs 供填 args/returns。

## 核心决策（已确认）

### 1. 一文档一树（取代方案 2 的主块+附属块）

- **每个行为树文档恰有一棵行为树**（一个根节点），无附属块概念。
- 文档名 = 树名；子树复用 = `ref: 文档名`（**跨文档引用**），不再有 `this/附属块`。
- 本树内部组织靠树结构（嵌套节点），创建"子块"= 在节点下加子节点。
- DSL 倾向直接裸树（`Sequence:` 开头）——待确认。

### 2. 根节点

- 每文档恰有一个**根节点**（特殊节点，无类型）。
- 根的子节点限制为 1；执行即执行其子节点（类似"子限制为 1 的 Sequence"）。
- **根不可删除/替换**。
- **ref 引用 = 挂载被引用文档的根节点**（把 B 的根挂到当前树的槽位）。

### 3. 节点对象池 + 槽位引用

- 画布上节点**独立存在**（对象池），父子关系通过**容器节点的槽位（下拉选择）**建立，而非物理嵌套。
- **槽位有序**：执行顺序 = 槽位顺序（Sequence 先槽位1 后槽位2）。
- 容器类型（Sequence/IfThenElse/Branch/Retry...）有槽位：
  - IfThenElse：固定 2 槽（then/else）+ 判断条件字段
  - Sequence：槽位数量可变，有「增加槽位」按钮
- **槽位下拉只能选"游离树的根节点"**（未被任何槽位引用的节点；单节点也是树，根即自身）——保证纯树结构、无共享子树成图、不可选项不展示（符合前端设计法则）。

### 4. 主树区 + 游离区（画布布局）

- 画布分两区：
  - **主树区**：从根递归槽位引用可达的节点，自动布局成树（**根在上、向下生长、兄弟水平排布**）。
  - **游离区**：根不可达的节点/树（游离树），独立结构化布局（同样根在上、向下生长、兄弟水平），自动堆叠在主树下方。
- 游离节点被槽位选中 → 从游离区移除、并入主树；主树子树被剥离 → 回游离区。

### 5. 节点创建：仅面板拖拽

- 暂只支持从节点面板拖拽到画布 → 生成游离节点/游离树。
- **不支持槽位直接新建**（两种方式前端呈现不同，当前不考虑）。

### 6. 删除/编辑语义矩阵（核心，需精确处理）

画布三层元素：节点对象、槽位连线、子树。每种动作明确"谁没了、谁留下、留下去哪"：

| 动作 | 删/改什么 | 结果 |
|---|---|---|
| 删槽位 | 一条连线 | 被解引用节点 + 其子树 → 游离区（整棵子树一起） |
| 删单节点 | 该节点 | 其槽位子节点**各自成为独立游离树**（回游离区）；删游离节点直接消失 |
| 删子树 | 节点 + 全部后代 | 无残留 |
| 改槽位选另一节点 | 改连线 | 旧节点回游离区，新节点入主树 |
| 改节点字段 | 纯改值 | 结构不变 |
| 改 ref 目标 | 换引用文档 | 被引用文档不受影响 |

边界情形：
- 删主树中间节点 → 其子节点各自成游离树。
- 删 ref 节点 → 仅解除引用，被引用文档毫发无损。

### 7. 节点命名（结构化）

- **类型前缀 + 字段首词描述**：`Step:登录`、`Sequence`、`ref:B`、`IfThenElse`。
- 同类型冲突时递增序号：`Sequence`、`Sequence(2)`。
- 便于槽位下拉中查找。
- 命名前缀沿用编辑器类型（Step 而非引擎层 Action）——待确认。

### 8. ref 引用呈现

- 收缩态：单节点占位卡片「引用: B」。
- 展开态：显示 B 的根 + 整棵子树（**只读预览**），逐层懒加载（B 里的 ref:C 默认仍是单节点，点击再展开）。
- 收缩 B → 其内已展开的 C 一并收缩。
- 修改被引用文档需进入该文档编辑，预览处不可改。

### 9. ref 参数编辑（属性面板）

选中 ref 节点 → 属性面板：

```
引用目标  块 ▾ [打开页面]               ← 下拉选文档（只显示存在的文档）
入参 (inputs)
  url : str   传入参数名 [______]       ← 每个入参填：父作用域中传入的变量名
出参 (returns)
  url文本     接收参数名 [______]       ← 填：父作用域新建的接收变量名
```

- 下拉选块后**自动加载该块的 inputs/outputs 声明**，生成参数映射表单。
- 入参 = 读父作用域变量（对应运行时 args 求值）；出参 = 写父作用域新建变量（对应运行时 returns 回收，后续节点可 `[[get:this/参数名]]` 引用）。

### 10. 校验体系（错误越早提示越好）

**游离树允许保存**：文档允许含游离树（未连接到根节点的部分可保存，支持中途保存退出/草稿）；单根校验 = **有且仅有一个 `type: Root` 节点**（不要求所有节点根可达）。

**无环校验**：主树与**每棵游离树**分别校验无环（防止导入用户自定义坏文档；即使槽位只选游离根使编辑中不会成环，导入校验仍需要）。

**校验时机分层**：
- **编辑时（即时）**：前端本地——节点必填字段（action/expect/max...）红框标记；ref 选目标文档后立即加载其 inputs/outputs → 校验 args/returns 对齐。
- **保存时（汇总）**：前端本地 + 后端权威——单根（恰一 Root）、主树/各游离树无环、ref 目标文档存在、节点配置字段齐全（含游离树节点）、ref 参数对齐。
- **导入时（一次性）**：解析用户自定义文档——nodes 平铺合法、slots 引用存在、单根、无环、参数对齐（防坏文档进入系统）。

**ref 参数对齐**（编辑时即可校验，因选引用树时已加载目标文档 inputs/outputs）：
- args 数量/顺序 = 被引树 inputs；args 元素（本树变量名）须存在于本树作用域。
- returns 数量 = 被引树 outputs；returns 键（本树新建参数名）不得与本树已有变量重名。
- **类型对齐**：args 传入变量类型 匹配 被引树 inputs 声明类型。

**节点配置层**（主树与游离树节点都校验）：IfThenElse 两槽必须有挂载；Step 必填 action+expect；Branch when 非空；LoopUntil/Retry 必填 max；ref 必选目标、入参必填；condition/判断字段非空。复用后端 M2 清晰度校验（/check 权威）。

### 11. 前端设计法则（已写入 AGENTS.md）

- **不提供不合理的选择**：下拉/选择器只展示当前可选项；容器槽位只展示游离根，已挂载节点不显示。
- **操作与结构语义一致**：删除槽位=解引用回游离区；删除单节点=子节点各自成游离树；删除子树=连带删后代。结果可预测、无歧义。

### 12. DSL 语法（一文档一树 + 文档级接口）

**文档自包含**：树名（=文档名）、节点 id/name、声明、配置全写在文档内，支持直接导入 .md/.yaml 创建行为树，导入时保留原文档 id。

```
# 行为树文档（自包含）
tree 订单流程:                          # 顶层键承载树名（=文档名，必需）
  inputs: {起始订单: str}               # 可选：接口入参（创建参数：字典+类型）
  outputs: [处理结果]                    # 可选：接口出参（传递参数：列表）
  timeout: 30                           # 可选：全局配置（保留名，含义固定）
  retry: 3
  nodes:                                # 节点对象池（平铺定义全部节点）
    n1:
      type: Root                        # 根节点（真实节点类型）
      name: 根
      slots: {1: n2}
    n2:
      type: Sequence
      name: 主流程
      slots: {1: n3, 2: n4}
    n3:
      type: Step
      name: 登录
      action: 点"登录"
      expect: 出现"工作台"
    n4:
      type: ref
      name: 处理B
      target: 文档B                      # ref 引用另一文档整棵树
      args: [起始订单]                   # 传参：列表，按序对应被引树 inputs
      returns: {结果: str}              # 接收：字典 {本树新建参数名: 类型}
  root: n1                              # 树根引用（指向 nodes 里 type: Root 的节点 id）
```

**节点模型**（画布卡片尺寸固定，类型用颜色/形状/图标区分）：
- 节点 = `{ id, type, name, 节点字段..., slots }`
- **id**：节点唯一标识（文档内唯一，供槽位引用/ref 定位/游离判定），自动生成（`n1/n2...`），**导入时保留原 id**
- **name**：用户自定义的纯字符串（画布显示名），**不包含类型前缀**——类型靠图标/颜色区分

**顶层键分类**：`tree <名>:`（文档名，恰一）+ `inputs`/`outputs`（声明）+ `timeout`/`retry`/`browser`（全局配置保留名）+ `nodes:`（节点池，必需）+ `root: <id>`（树根引用，指向 nodes 中 `type: Root` 节点）；其他键报错。

**槽位引用（方案 B：平铺 + 引用）**：
- 父子关系 = 容器节点的 `slots: {1: <子id>, 2: <子id>}`（有序）
- 节点在 `nodes:` 下按 id 平铺定义，独立存在（对象池）
- 游离判定 = 未被任何 slots 引用的节点；根可达 = 从 `root` 沿 slots 遍历
- **Root 是真实节点类型**（与 Step/Sequence 同级别，首字母大写）：固定 1 槽位（子限制 1），执行即执行其子节点；每棵树根必然 `type: Root` 的节点，id 走统一生成规则，顶层 `root: <id>` 引用（做法乙）

**ref 参数对称**（创建=字典+类型，传递=列表）：

| 方向 | 创建参数（字典+类型） | 传递参数（列表） |
|---|---|---|
| 被引树 | `inputs: {name: str}`（入参声明） | `outputs: [p1]`（出参声明） |
| 引用树 | `returns: {结果: str}`（**本树接收名**:类型，按序对应 outputs） | `args: [name]`（**本树变量名**，按序对应 inputs） |

- `this/变量` 指向本文档执行帧：`inputs` 注入本帧 `this/入参名`；`[[set:...:this/x]]` 本帧局部；`outputs` 本帧声明输出（节点 set 或 ref returns 目标赋值）。
- 改名 = 改 `tree` 键 + 存储名（前端一处联动），存储名 = `tree` 键值，无两个名字冲突。

### 13. 画布布局算法

**节点卡片**：尺寸固定（所有节点相同），画布不显示字段详情——仅**类型图标/颜色 + name**。类型用颜色/形状/图标区分。

**单棵树布局**（自底向上算宽、自顶向下定位，根在上、向下生长、兄弟水平均布）：
- 常量：节点宽 W、高 H、水平间距 gapX、垂直间距 gapY。
- 递归 `layout(N) → 包围盒(w,h)`：叶子返回 (W,H)；否则子们按槽序水平均布，`w = max(W, Σ子w + gapX·(n-1))`，`h = H + gapY + max(子h)`，N 居中于子们上方。
- 定位：Root 放 (0,0)，子节点依序定位（x 均布、y = 父.y + H + gapY）。

**主树区 + 游离区**：
- 主树：从 `root` 节点递归布局（画布左上）。
- 游离树：遍历 nodes，未被任何 slots 引用的节点为游离树根；每棵用同一布局函数，逐棵排布在主树包围盒下方（或右侧），树间留间距 treeGap；**每棵游离树顶部加小标签**（根节点 name + 「游离」标记）。
- 画布总尺寸 = 主树盒 ∪ 游离树盒；视口可平移/缩放，横向长树可滚动。

**连线绘制**（SVG ortho，连线在节点下层）：
- 父子连线：父底部中点 → 子顶部中点，正交折线：`M父.x 父.bottomY / V 父.y+H+gapY/2 / H 子.x / V 子.y`。

**ref 展开**：展开的 ref 子树嵌入当前树布局（视为可展开容器，展开时子树参与父树的兄弟排布）；收缩即回到单节点占位。

**性能**：当前全量布局（不做视口裁剪/性能优化）；多数行为树节点规模小（< 100）。

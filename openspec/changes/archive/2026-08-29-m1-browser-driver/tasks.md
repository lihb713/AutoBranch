## 2. 会话生命周期

- [x] 2.1 实现 `start`（创建全新 context，注入浏览器类型与全局 timeout 配置）与 `stop`（关闭 context 与全部页面）；验证真实浏览器集成测试：start 后可打开页面，stop 后 context 与页面全部关闭

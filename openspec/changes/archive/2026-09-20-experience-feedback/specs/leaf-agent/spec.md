## MODIFIED Requirements

### Requirement: 叶子执行的提示词设计

系统 SHALL 为叶子执行提供统一的系统提示词，将节点自然语言描述与当前语义图转化为可靠的决策依据，指导 LLM 正确调用引擎函数、执行多轮定位与得出判断；提示词随输入保持稳定，使相同输入下的 LLM 决策可被回归验证。系统 SHALL 支持在叶子用户消息末尾**可选注入"上次成功执行参考"段**（仅当同执行结构 + 同入参 + 同节点命中经验时），并以"参考而非指令"的姿态呈现——明示"仅供参考，以当前语义图为准；与当前页面状态不符时忽略经验"；无经验命中时，提示词与无经验回灌完全一致。经验查询经叶子执行上下文注入的回调解析（叶子侧不直接依赖存储）。

#### Scenario: 固定输入下决策可回归

- **WHEN** 以固定的节点描述与固定语义图作为 LLM 输入
- **THEN** 系统以一致的方式组织输入并提供给 LLM，使决策结果可被记录并与后续运行比较以回归保护

#### Scenario: 提示词引导函数调用

- **WHEN** LLM 收到 Action 叶子节点的描述与语义图
- **THEN** 系统提供的提示词使 LLM 得以选择并调用合适的引擎函数与目标元素，而非直接给出无法执行的结果

#### Scenario: 命中经验时注入参考段

- **WHEN** 叶子命中同结构 + 同入参 + 同节点的历史成功经验
- **THEN** 系统在该叶子用户消息末尾注入参考段，明示以当前语义图为准、与当前状态不符时忽略

#### Scenario: 未命中经验行为不变

- **WHEN** 叶子未命中任何经验（或经验回灌关闭）
- **THEN** 该叶子提示词与无经验回灌完全一致

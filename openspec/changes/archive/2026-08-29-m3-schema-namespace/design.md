## Context

- 契约定义见 `docs/contract.md` §5.3（变量 schema 命名空间机制）、§5.3.2（可见性规则）、§5.3.4（配置参数继承）、§5.3.5（类型契约）、§5.7.4（帧模型）、§5.10（页面变量机制）；动机见 proposal.md - Why，需求见 `specs/schema-namespace/spec.md`。
- 本模块为纯逻辑层：无 I/O、无浏览器/LLM 依赖，接口契约由 `docs/specs/M3-schema-namespace.md` §5.1 给定（`SchemaSpace.enter_block` / `write` / `read` / `resolve_config`）。
- 消费方：M7 编排器在每次块引用时 `enter_block` 建立帧并读写变量；M5 引擎函数层通过 `write`/`read` 落地 extract 写变量、open 写页面引用与函数页面绑定。

## Goals / Non-Goals

**Goals:**
- 提供确定性的帧模型与严格作用域校验，纯内存数据结构操作
- 提供配置参数三级继承（自身 → 最近祖先 → 全局默认）与根级默认注入
- 提供类型契约与「断言失败终止」语义
- 提供页面引用（PageRef）类型的存储、传递与当前页面变量绑定解析

**Non-Goals:**
- 不涉及浏览器 / LLM / 文件 I/O
- 不做行为树遍历（M7）与引擎函数（M5）的实现
- 不实现页面生命周期管理（释放由行为树执行结束统一触发）
- 不做配置参数具体名称的注册表（timeout/retry 名称由工具配置侧提供）

## Decisions

### 决策 1：SchemaFrame 为独立存储单元，SchemaSpace 为门面

每次 `enter_block` 分配独立 frame，帧保存 parent 指针与自身路径段。

- 备选：共享全局 dict + 前缀过滤。放弃：隔离性难保证，路径别名易产生越权泄漏。
- 理由：独立帧使「同名不冲突」与「帧隔离」天然成立；作用域校验只需检查路径首段是否为自身或直接子块。

### 决策 2：帧内以相对路径字符串为 key 平铺存储

每帧内部用 dict，key 为相对路径（如 `amount`、`登录/username`），路径按 `/` 分层解析。

- 备选：嵌套 dict 结构。放弃：写入需逐层建节点，易产生深拷贝与引用别名问题。
- 理由：平铺 + 路径解析简单，读/写/校验一步完成，便于单元测试矩阵覆盖。

### 决策 3：作用域校验集中在单一入口

`write`/`read` 前统一校验路径首段：`$this`（自身）或某个直接子块名，否则报越权校验错误。

- 备选：调用方各自校验。放弃：分散易漏。
- 理由：单入口保证越权规则不被绕过，可用作用域矩阵测试穷举覆盖。

### 决策 4：配置继承用 parent 链向上查找，根级帧注入全局默认

`resolve_config(frame, name)`：自身帧未定义 → 沿 parent 链向上 → 根级帧的全局默认。

- 备选：每帧创建时快照全量配置。放弃：父块覆盖后子块读不到最新值，违背「引用子块时子块自身配置优先」。
- 理由：动态查找保持继承链最新；业务变量走 `write`/`read` 严格作用域，与 `resolve_config` 分开，天然不向上查找。

### 决策 5：类型校验双时机——写入即时校验 + 提取强校验

SUPPORTED_TYPES 集中登记类型与校验函数；写入时声明类型并即时校验，提取/读取时对声明类型二次强校验，不匹配触发断言失败（以统一异常终止）。

- 备选：仅写入时校验。放弃：契约要求「提取错误则断言失败并终止」，存储侧可能被上层绕开。
- 理由：与 §5.3.5 语义一致，且 `docs/specs/M3-schema-namespace.md` §5.4 明确要求读取/提取时强校验。

### 决策 6：PageRef 作为普通类型值，绑定解析留在上层

页面引用只是一类 Value（携带页句柄），存储、传递、类型校验与普通变量一致；「当前页面变量」的解析由 M5/M7 决定。

- 备选：SchemaSpace 内维护「当前页」状态。放弃：会把浏览器/会话概念耦合进纯逻辑层。
- 理由：保持 M3 纯逻辑；多页面变量的写入/传参/绑定测试仍可在本层完成。

## Risks / Trade-offs

- [变量名含 `/` 导致路径解析歧义] → 限制变量名不得包含 `/`，路径固定按 `/` 分层，路径解析函数单测覆盖。
- [作用域校验遗漏导致越权泄漏] → 集中单一校验入口 + 完整作用域矩阵测试（祖先/兄弟/孙子全组合）。
- [配置继承优先级与块覆盖混淆] → `resolve_config` 单一入口 + 继承链三级测试，明确「自身优先」。
- [类型断言失败以异常终止，需与 M7 失败传播衔接] → 定义统一断言失败异常类型，M7 捕获后沿树传播（见 §5.7.7）。
- [全局默认注入时机] → 约定 SchemaSpace 初始化时注入根级帧一次，此后不随工具配置变化重建。

## Migration Plan

- 全新模块，无既有实现迁移。落地时同步维护 `docs/specs/M3-schema-namespace.md` 与 `docs/contract.md` 的一致性。
- 回滚策略：本模块无外部副作用，移除模块文件即可回滚，不影响其他模块。

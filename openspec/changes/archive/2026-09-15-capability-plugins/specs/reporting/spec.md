## ADDED Requirements

### Requirement: 插件驱动的报告结构

报告 SHALL 由「引擎基础字段」（节点类型 / 描述 / 结果 / 时间戳 / 工具调用记录 / LLM 轨迹）+「插件附加信息」组成。系统 SHALL 提供统一的、结构化的报告写入接口：插件函数通过**返回值**携带报告附加信息，引擎落笔写入并按来源分组，随报告持久化；插件附加信息 SHALL 为结构化 `{来源: 插件名, sections: [...]}`。引擎 SHALL NOT 硬编码能力专属字段（如页面 URL / 截图）。截图 SHALL 由浏览器插件在 `semantic_graph`（"看页面"）时产出并写入报告，不再由编排器无条件截。

#### Scenario: 引擎基础字段
- **WHEN** 任一节点执行
- **THEN** 报告含节点类型 / 描述 / 结果 / 时间戳 / 工具调用记录 / LLM 轨迹

#### Scenario: 插件附加信息
- **WHEN** 插件函数返回值携带报告附加信息
- **THEN** 引擎将其写入报告，渲染时按来源展示

#### Scenario: 截图由浏览器插件产出
- **WHEN** 调用 `semantic_graph`
- **THEN** 浏览器插件截图并写入报告；非浏览器操作不产生截图
